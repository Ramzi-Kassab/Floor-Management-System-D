## FC Bit Production Flow (from SA-PP-104)

Sub-Arc Weld → Braze → Die Check → Tip Grind → Shank Machining →
Pressure Test/Die Check → Nozzle Liners → Final Inspection → Paint & Box

## RC Bit Production Flow (from SA-PP-104)

Component Handling → Tack Weld/Gouge → Sub-Assembly → Ball Plug Weld →
Pressure Test → Tack Weld Arms → Dome Weld → Seam Weld →
Chipping/Grinding/Gauging → Pin Turn/Shank Turn → Pressure Test (Jet) →
Grease → Final Inspection → Paint & Box

## Training & Competency Requirements (SA-QP-6.1)

- New employees: meet QAS/021 qualifications, QAS/031 induction, 90-day probation
- Welding/Brazing: individually certified per HDBS program
- NDE (LPT): certified per SA-PP-1013, re-qualified every 5 years
- Eye/color test: every 12 months
- Key Personnel changes: MOC per SA-ARDT-STD-001
- CTO (Certified to Train Others): requires signed QAS/025

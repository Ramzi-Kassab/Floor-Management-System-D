## Key Details

### RC Welding Procedures (SA-PP-12, 13, 14, 15)
- All welders certified per HDBS WM-CONWO-HAL-QM-602C
- **Tack (SA-PP-12)**: X coordinate from router card, tempil stick monitoring, max 250 F
- **Dome (SA-PP-13)**: E7018 electrode, multi-pass fill 3/32" above flush
- **Seam (SA-PP-14)**: GMAW, copper chill bar dam, cap pass with flux core wire <=12 1/4"
- **Burnout (SA-PP-15)**: Electrode/amperage table by bit size, groove width/depth specs

### SA-PP-31 Jet Pressure Testing
- Minimum 40 PSI, pressure decay test stand
- Green light = pass, Red = fail
- Fail: soapy water leak detection, NCR per SA-PP-113
- Trained Floor Technicians only

### SA-PP-34 Sub Assembly (RC)
- Clean room rules for sub-assembly
- EPI soap solution wash at 140-160 F
- Ball bearing count verified with ball plug gauge
- Form: QAS/34.1 Change of Solution Log

### SA-PP-48 Lubrication
- Automatic Vacuum Machine: weekly checkout, vacuum 27.0 in Hg minimum
- Type 1 (Dome Vent): Belleville washer concave out, 220-250 in-lbs torque
- Type 2 (Ball Pressure): Fill to 1000 PSIG hold 60s, 300-330 in-lbs torque
- Form: QAS/003 Checkout Form

### SA-QP-4.1.1 Calibration Control
- Traceability to international/national standards
- Color-coded gages: yellow=final, green=process, white=tack-up
- Controlled environment: 68 F +/-2, 30-50% RH, 24hr soak
- Frequency codes: M=monthly, Q=quarterly, T=tri-annual, S=semi-annual, A=annual
- Out-of-calibration: trace back through inspection stations, product validation
- Forms: Exhibit A (Serial Numbers), B (Calibration Record), C (Gage Readings), D (Product Validation)

### SA-QP-4.1.2 Calibration Methods
- Ring gages: 6-point inside micrometer, +0.003/0 Go, 0/-0.003 No-Go
- Snap gages: gage blocks, +/-0.001
- API thread working ring: reference plug gage, standoff 0.621"-0.629"
- Forms: QAS/008, QAS/024

### SA-QP-9.2 Documents and Records Control
- Document coding: SA-PP-xx (processing), SA-QP-xx (quality), QAS/xxx (forms)
- Revision sequence: 0, A, B, C, D, E...
- Records retained minimum 10 years per API Q1
- Annual review (QAS/106), half-yearly point-of-use inspection (QAS/056)
- Forms: QAS/9.2, QAS/019, QAS/020, QAS/046, QAS/056, QAS/059, QAS/106

### SA-PP-1009 Customer Property
- Tag colors: Saudi ARAMCO = Blue, Halliburton = Beige, Scrap = Red
- Monthly inventory (LSTK by coordinator, ARAMCO by Repair team)
- Store in original customer container
- Forms: QAS/1200, QAS/2001-1 Bit Evaluation Forms

### Quality Policy (Rev E, 09/15/2024)
- Standards: ISO 9001:2015, API Q1 10th Edition
- Scope: "Design, Manufacture and Repair of Fixed Cutter Bits; Manufacture of Roller Cone Bits"
